# Lumina Horizon

Sitio institucional de Lumina Horizon.

## Enfoque

Lumina Horizon es una iniciativa tecnológica en construcción, enfocada en innovación, desarrollo digital y accesibilidad. Este sitio comunica únicamente información institucional y estados de proyectos que han sido definidos; no utiliza cifras, testimonios, alianzas ni capacidades sin verificar.

## Ecosistema

- **Eteris Radio:** submarca enfocada en radio digital. Estado: proyecto en desarrollo.
- **Lazarus:** submarca enfocada en software, orientación y movilidad asistida por IA para personas con discapacidad visual. Estado: en desarrollo.
- **Lumina Horizon Media:** división interna dedicada a contenidos audiovisuales y editoriales.

## Tecnología

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000).

## Construcción de producción

```bash
npm run build
npm run start
```

## Identidad y contenido

La identidad visual utiliza negro profundo, azul eléctrico, cian, plateado y blanco. El logotipo institucional se conserva en `public/Lumina_horizon.png`.

Antes de publicar, verificar dominio, canales de contacto, enlaces sociales, textos legales y estado real de cada proyecto. No publicar información de contacto ni funcionalidades que no hayan sido confirmadas.
